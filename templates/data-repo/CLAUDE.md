# Job triage — my data

Private data repository for the `job-triage` code repository. The skills live
there and read these files; there is no code here and never will be.

## Rules

- Never push to a public remote.
- `criteria.md` decides every verdict. Read it before judging a vacancy, and
  update it in the same session when I correct a verdict.
- `linkedin/ledger.json` is written by `linkedin.py record`, not by hand.
- `linkedin/session.json` is a credential. Never print it, never commit it.
- `triage/` gets one Markdown report per run, named `<date>-vacancies.md`.
